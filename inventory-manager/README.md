# 📦 Inventory Manager

Este é um projeto desenvolvido para treinar lógica de programação, manipulação de dicionários, funções e organização de fluxo em Python.

**O objetivo é simples:** gerenciar produtos em um sistema de estoque via terminal, permitindo adicionar, listar, atualizar e remover produtos.
<br>

## ✨ Sobre o Projeto

Neste sistema, os produtos são armazenados em um dicionário utilizando IDs únicos para evitar sobrescrita de dados. <br> O usuário pode interagir com o sistema através de um menu no terminal.

**O sistema também:**

- adiciona novos produtos
- lista os produtos em ordem alfabética
- atualiza a quantidade de produtos
- remove produtos do estoque
- organiza os dados utilizando dicionários aninhados

<br>

## 📁 Estrutura de Arquivos

O projeto está organizado da seguinte forma:
