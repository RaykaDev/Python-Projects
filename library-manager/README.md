# 📚 Library Manager
Este é um projeto desenvolvido para treinar lógica de programação, gerenciamento de dados e manipulação de dicionários em aplicações de terminal com Python.
**O objetivo é simples:** gerenciar uma biblioteca de livros via terminal, permitindo adicionar, listar, remover, atualizar exemplares e registrar empréstimos.
<br>

## ✨ Sobre o Projeto
Neste sistema, os livros são armazenados em um dicionário utilizando o título do livro como chave e um dicionário interno como valor, contendo o nome do autor e a quantidade de exemplares disponíveis. <br> O usuário pode interagir com o sistema através de um menu no terminal.

**O sistema também:**
- adiciona novos livros com título, autor e quantidade de exemplares
- lista livros cadastrados em ordem alfabética
- remove livros existentes
- atualiza a quantidade de exemplares de um livro
- registra empréstimos e controla a disponibilidade de exemplares
- exibe o histórico completo de empréstimos realizados
- organiza os dados utilizando dicionários aninhados

<br>
