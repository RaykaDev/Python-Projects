# ✅ Task Manager

Este é um projeto desenvolvido para treinar lógica de programação, gerenciamento de tarefas e manipulação de dicionários em aplicações de terminal com Python.

**O objetivo é simples:** gerenciar tarefas via terminal, permitindo adicionar, listar, concluir e remover tarefas.
<br>

## ✨ Sobre o Projeto

Neste sistema, as tarefas são armazenadas em um dicionário utilizando o nome da tarefa como chave e um valor booleano para indicar seu status de conclusão. <br> O usuário pode interagir com o sistema através de um menu no terminal.

**O sistema também:**

- adiciona novas tarefas
- lista tarefas em ordem alfabética
- marca tarefas como concluídas
- remove tarefas existentes
- organiza os dados utilizando dicionários

<br>

## 📁 Estrutura de Arquivos

O projeto está organizado da seguinte forma:

- `gerenciadorTarefas.py`: Script principal contendo toda a lógica do sistema.
